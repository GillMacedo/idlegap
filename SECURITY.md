# Security

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/GillMacedo/idlegap/security/advisories/new), not in a public issue.

`idlegap` only reads files. It never builds or runs the code it checks, and it doesn't contact a cluster or a cloud API. A wrong answer is a normal bug, unless it reports a setup as fine when it isn't in a way that could hide an outage. If it could, you may report it privately.
